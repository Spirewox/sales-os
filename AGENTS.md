## UI work

Before you add or change a component, a screen, a style, a token, or copy in the UI:
1. Read public/llms.txt, then public/system/rules.md and the twin in public/system/ of each component you touch (sources in docs/system/, registry in registry.json).
2. Use a component from `@/components/app` (the kit) or `@/components/ui` (primitives) and the tokens in app/globals.css, the one token source. Its header comment holds the visual rules: one green accent, status colours only for real state, smallest text text-xs, sentence case, cards rounded-xl, controls rounded-md. If nothing fits, say so in your final message before writing a new one.
3. Copy: customers are contacted by WhatsApp only (no Call buttons), markups are percentages, no em-dashes in UI text. Never remove a KPI, chart, section, column or field unless the same information is visible elsewhere, and say where.
4. See the component in Storybook: `npm run storybook` (port 6006), or `npm run build-storybook`. Add or update its story in stories/ when you change a component.
Before you finish: run `node scripts/check.mjs`, and look at the changed screens at 390 and 1280 px in both themes.
`node scripts/check-system.mjs --explain <rule-id>` gives the fix for a finding.
